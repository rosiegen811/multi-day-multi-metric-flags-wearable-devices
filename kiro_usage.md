# Kiro Usage Write-Up

**Tooling & spec-driven development.** We built this entirely through Kiro's spec-driven workflow, orchestrated from the agent/CLI surface rather than ad-hoc chat. The spec started from a README pitch, which we turned into a formal three-document spec: a requirements.md with 15 EARS-style acceptance criteria, a design.md with a module architecture, the shared `Per_Window_Table` contract, and 28 named correctness properties, and a tasks.md dependency graph of 19 tasks. Because every module (data loaders, cleaner, windower, baseline, scorer, flagger, movement check, explainer, evaluator, calibrator) was pinned to specific acceptance criteria and a shared data contract *before* any code was written, we could dispatch tasks to execution sub-agents in parallel waves and have them integrate cleanly — a loader written in isolation still produced exactly the table the scorer expected. Compared to vibe coding, the difference showed up at integration time: the full pipeline wired together end-to-end on the first attempt on synthetic data, and when real data later exposed genuine bugs (datetime headers, subset-of-signals Mahalanobis, artifact spikes, a degenerate baseline-spread that let one signal dominate), the spec let us reopen exactly the owning task, fix it against its acceptance criteria, and re-verify without regressing neighbors. Vibe coding would have produced a tangle of implicit assumptions that the real E4 data would have shattered.

The work was pure spec + task-execution sub-agents plus Kiro's own capabilities (file/codebase search, shell execution for real-data verification, web search to confirm the PhysioNet dataset's provenance and license). On property-based testing: the design specifies 28 correctness properties (parsing round-trips, windowing boundaries, z-score sign/magnitude, gate/tier/hysteresis monotonicity, LOSO partitioning, FHIR round-trip) and the Hypothesis harness is scoped in tasks.md, but those test sub-tasks were deliberately deferred to ship the working pipeline first and remain unwritten
